# Security policy

## Reporting a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/lesloi/path-finder/security/advisories/new),
not in a public issue.

Privacy leaks count as vulnerabilities, for example the API logging or keeping a location
or an IP address, or the app calling a third party other than the IGN Géoplateforme.

## Supported versions

Only the latest version on `main`, published as the `latest` Docker image, gets fixes.
